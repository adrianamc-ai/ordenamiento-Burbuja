# ordenamiento-Burbuja

En esta practica hago uso del método de burbuja que basicamente es comparar dos formas de ordenar una lista de números en Java:
1. Burbuja Normal: Recorre toda la lista varias veces hasta ordenar los números.
2. Burbuja Mejorada: Detecta si la lista ya está ordenada antes de tiempo y se detiene para ahorrar trabajo.

OrdenamientoBurbuja.java Contiene los métodos de ordenamiento y las pruebas con listas desordenadas y ordenadas.
